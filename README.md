# TecnoCatalogoVirtual
DESARROLLO DE SOFTWARE EN EQUIPO - TSP-

El presente proyecto tiene como finalidad planificar y organizar el desarrollo de un catálogo virtual de tecnología y productos electrónicos, que permita a los usuarios consultar productos, conocer sus características, verificar su disponibilidad y gestionar sus compras.
Para su desarrollo se utilizarán HTML, CSS y JavaScript, buscando construir una interfaz intuitiva, organizada y fácil de utilizar.
El equipo aplicará los principios de la metodología Team Software Process (TSP), estableciendo roles, responsabilidades, actividades y reuniones para realizar una adecuada planificación y seguimiento del proyecto.
